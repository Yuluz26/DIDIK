# Important production-status notes
- **Concept art / reference scene**: AI-generated composite art. Boss, hero, UI or scenery may be baked into the image. It is **not** a clean gameplay map, animation sprite, or collision-ready background.
- **Upscaled/resized presentation**: FHD image dimensions do not imply additional native image detail.
- **UI layer PNG / SVG**: actual reusable graphic assets; render question text, names and changing HP separately using your game engine.
- **MP4 animatic**: a real playable video file made by compositing and/or camera-panning static images. It is **not** footage of a working JRPG and does not contain frame-by-frame character animation.
- Existing five elemental powers: api, angin, petir, tanah, air (no sixth element 'bayangan').
- Quiz validation, HP updates and boss progression must remain authoritative in DIDIK Live backend.
- Story Mode is auto exploration + cinematic encounter + JRPG quiz battle: **no joystick/WASD**, no 3D games.
