# 06. WORLD 4 — RIMBA BAYANGAN

## Theme
Hutan mistik yang gelap, ajaib dan sedikit menyeramkan, berkait dengan Sang Kancil Bayangan.

## Required visual mood
- Moonlit forest
- Purple/blue ambience
- Bioluminescent plants
- Spirit lights
- Ancient ruins
- Magical symbols
- Fog / mist
- Enchanted tree shapes
- Dreamlike haunted beauty

## Core assets required
### A. Key art / overview
- World 4 key visual poster
- Rimba Bayangan chapter intro image
- World thumbnail icon
- World map preview / chapter card

### B. Auto story / transition backgrounds
- Shadow trail background
- Magical ruins transition background
- Encounter lead-in frame
- Chapter clear background

### C. Battle backgrounds
- Standard shadow forest encounter background
- Spirit ruins battle background
- Boss battle background
- Optional nightmare phase background

### D. Minor enemy assets

- Shadow sprite
- Spirit stalker
- Illusion guardian

Each needs:
- concept art

- hurt frame
- defeated frame
