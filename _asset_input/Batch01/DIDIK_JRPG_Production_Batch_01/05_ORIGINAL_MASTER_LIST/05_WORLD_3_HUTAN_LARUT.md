# 05. WORLD 3 — HUTAN LARUT

## Theme
Hutan hujan tropika Malaysia yang tebal, purba dan penuh penjaga rimba.

## Required visual mood
- Ancient rainforest
- Giant trees
- Hanging vines
- Ferns and jungle shrubs
- Mossy ruins
- Shrine stones
- Streams / small waterfall
- Green light shafts
- Humid mystical atmosphere

## Core assets required
### A. Key art / overview
- World 3 key visual poster
- Hutan Larut chapter intro image
- World thumbnail icon
- World map preview / chapter card

### B. Auto story / transition backgrounds
- Jungle pathway background
- Forest shrine transition background
- Encounter lead-in frame
- Chapter clear background

### C. Battle backgrounds
- Standard forest encounter background
- Ruins encounter background
- Boss battle background
- Optional heavy rain phase background

### D. Minor enemy assets
At least 3 types:
- Jungle sentinel
- Vine crawler
- Shrine guardian

Each needs:
- concept art

- attack cue frame
- hurt frame
- defeated frame
