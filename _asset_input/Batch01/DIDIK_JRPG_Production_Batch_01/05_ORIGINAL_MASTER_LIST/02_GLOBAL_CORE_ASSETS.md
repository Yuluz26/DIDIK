# 02. GLOBAL CORE ASSETS

## 1) GAME SYSTEM DIRECTION
Struktur gameplay baharu:
- Auto story progression
- Encounter trigger
- Battle scene JRPG
- Soalan = sumber tindakan
- Betul = serangan / heal kecil
- Salah = boss / musuh serang

## 2) HERO ASSET BREAKDOWN

Setiap hero minimum memerlukan:
1. Character selection portrait
2. Full body promotional art
3. Battle idle pose
4. Attack pose
5. Hurt pose
6. Defeated pose
7. Victory pose
8. Element casting variant
9. Face portrait for dialogue / battle UI
10. Chibi battle sprite / pseudo-sprite version

## 3) ELEMENT SET ASSETS
Untuk **Api / Angin / Petir / Tanah / Air**:
- Passive icon
- Hover/active icon
- Equipped icon
- Attack slash FX
- Hit burst FX
- Aura glow FX
- Ultimate/cinematic overlay FX
- Element tooltip card art

## 4) REWARD SYSTEM ASSETS
- XP / progress star icon
- World clear medal
- Perfect answer streak icon
- Critical hit badge
- Weakness exploit badge
- Bonus knowledge reward badge

## 5) SYSTEM SCREENS
- Title splash
