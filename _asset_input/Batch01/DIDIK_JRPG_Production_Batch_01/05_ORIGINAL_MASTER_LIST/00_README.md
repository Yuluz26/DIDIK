# DIDIK JRPG Story Mode — Master Asset Pack

Pakej ini mengandungi **senarai lengkap asset** yang diperlukan untuk membina DIDIK Story Mode berasaskan **JRPG battle scene** dan **auto story progression**, mengikut flow yang kita bincangkan.

## Kandungan
- `01_MASTER_ASSET_LIST.md` — senarai penuh mengikut kategori
- `02_GLOBAL_CORE_ASSETS.md` — asset asas seluruh game
- `03_WORLD_1_TASIK_CHINI.md`
- `04_WORLD_2_BATANG_LUPAR.md`
- `05_WORLD_3_HUTAN_LARUT.md`
- `06_WORLD_4_RIMBA_BAYANGAN.md`
- `07_WORLD_5_GUNUNG_LEDANG.md`
- `08_UI_BATTLE_UX.md` — UI/HUD/Question/Battle flow
- `09_VIDEO_PROMO_ASSETS.md` — asset untuk trailer / promo
- `10_PRODUCTION_PRIORITY.md` — susunan cadangan produksi
- `DIDIK_asset_inventory.csv` — inventori ringkas dalam format spreadsheet

## Konteks gameplay
- **Bukan** top-down free movement seperti action game.
- **Ya** kepada struktur: Story progression + encounter + **JRPG battle scene**.
- Student **tidak perlu** gerak kiri/kanan untuk dodge.
- Soalan kuiz menjadi pencetus serangan / damage.
- Semua **4 game 3D lama perlu dibuang** dari sistem.

## Matlamat utama
Pakej ini adalah blueprint supaya Codex / developer boleh faham:
1. asset apa yang perlu dibuat,
2. keutamaan setiap asset,
3. state/variation yang diperlukan,
4. bagaimana setiap asset digunakan dalam gameplay sebenar.
