fetched from `https://fonts.gstatic.com/s/e/notoemoji/latest/<code point>/512.png`.

`live/web/scripts/story_assets.py --only emblems` sets them on the story mode's world and element
medallions (static/story/ui/symbol_*.webp and element_*.webp).
